# Landing Page: Sustentabilidade no Dia a Dia (Agenda 2030)

Esta é uma **Landing Page de Página Única (Single Page Application)** responsiva, criada para conscientizar sobre a importância da sustentabilidade no cotidiano, alinhada aos **Objetivos de Desenvolvimento Sustentável (ODS) da Agenda 2030 da ONU**.

---

## 🚀 Tecnologias Utilizadas
* **HTML5**: Estrutura semântica e acessível.
* **CSS3**: Estilização customizada com variáveis de cores ecológicas.
* **Bootstrap 5 (via CDN)**: Framework para responsividade rápida, grid e componentes.
* **Bootstrap Icons (via CDN)**: Ícones explicativos e visuais.
* **JavaScript (Vanilla + Bootstrap Bundle)**: Validação de formulário e controle do modal de confirmação.

---

## 🧩 Componentes Bootstrap Implementados
1. **Navbar (Navegação Ficha)**: Menu de topo com rolar suave (`scroll-behavior`).
2. **Carousel (Hero Banner)**: Banners rotativos com frases motivacionais e botões de chamada de ação.
3. **Cards**: Cartões de conteúdo para apresentar as dicas de reciclagem, água e energia.
4. **Accordion (FAQ)**: Pergunta e resposta expansível sobre a Agenda 2030 da ONU.
5. **Formulário de Cadastro Interativo**: Validação de campos e seleção de preferências de hábitos sustentáveis.
6. **Modal**: Caixa de diálogo exibida dinamicamente após o envio correto do formulário.

---

## 🛠️ Como Publicar no GitHub Pages

1. **Crie um repositório no GitHub** (ex: `sustentabilidade-agenda2030`).
2. **Faça o upload dos arquivos**:
   - `index.html` (o arquivo principal contendo o código da página).
   - `README.md` (este documento de apresentação).
3. Vá em **Settings (Configurações)** do seu repositório no GitHub.
4. No menu lateral esquerdo, clique em **Pages**.
5. Em **Build and deployment > Branch**, selecione a branch `main` (ou `master`) e a pasta `/ (root)`.
6. Clique em **Save**.
7. Após alguns segundos, o GitHub fornecerá o link público do seu projeto.
